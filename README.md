# Mobile-Sales-dashboard
📱 Mobile Sales Dashboard | Power BI Project
🚀 Project Title

Mobile Sales Dashboard – Interactive Sales Performance Analysis using Power BI

📌 Project Overview

This Power BI dashboard provides a comprehensive analysis of mobile phone sales performance across different brands, models, cities, payment methods, and time periods. The dashboard helps stakeholders monitor sales trends, track key performance indicators (KPIs), compare year-over-year performance, and gain actionable insights for business decision-making.

The project transforms raw sales transaction data into interactive visualizations, enabling users to explore sales patterns, customer behavior, and revenue performance efficiently.

🎯 Purpose

The main objective of this dashboard is to:

Monitor overall mobile sales performance.
Analyze sales trends across months, quarters, and years.
Compare current sales with previous period performance.
Identify top-performing brands and mobile models.
Understand customer purchasing behavior and payment preferences.
Support data-driven business decisions through interactive reporting.
